# J.A.R.V.I.S PRO — نسخه‌ی پیشرفته (وب/اپ نصبی)

نسخه‌ی خیلی پیشرفته‌تر از جارویس وب قبلی. همان روش نصب (بدون APK، بدون Buildozer) ولی با قابلیت‌های واقعی هوش مصنوعی عامل (agent).

## تفاوت با نسخه‌ی قبلی
نسخه‌ی قبلی فقط یک بار به مدل پیام می‌داد و جواب JSON را حدس می‌زد. این نسخه از **Function Calling واقعی** استفاده می‌کند: خود مدل تصمیم می‌گیرد کدام ابزار را چند بار صدا بزند و نتیجه‌ی واقعی هر ابزار را می‌بیند و بر اساس آن ادامه می‌دهد.

## امکانات جدید
- **۲۲ ابزار واقعی**: آب‌وهوای زنده (Open-Meteo)، جستجوی ویکی‌پدیا، ماشین‌حساب دقیق، تایمر و یادآور، یادداشت، حافظه‌ی درازمدت (`remember`/`forget`)، وضعیت گوشی (باتری/آنلاین)، موقعیت GPS، کپی به کلیپ‌بورد، تماس/پیامک/ایمیل، نقشه، تغییر تم، و باز کردن سایت/اپ/یوتیوب/گوگل
- **چند گفتگوی جدا** با پنل کناری، قابل حذف
- **ارسال عکس** به هوش مصنوعی (دوربین یا گالری)
- **جستجوی زنده‌ی گوگل** از طریق خود Gemini (دکمه‌ی SEARCH)
- **رندر کامل Markdown**: جدول، کد با دکمه‌ی کپی، لیست، لینک
- دیالوگ جدا برای **یادداشت‌ها** و **تایمرها** (در منوی ☰)
- **۵ تم رنگی**، اندازه‌ی قلم، سرعت صدا
- **پشتیبان‌گیری/بازیابی کامل** از تنظیمات → دادهها → خروجی گرفتن/وارد کردن

## نصب — دقیقاً مثل قبل
1. در GitHub یک مخزن **جدید و Public** بسازید.
2. همه‌ی ۸ فایل این پوشه را در ریشه‌ی مخزن آپلود و Commit کنید:
   `index.html`، `style.css`، `core.js`، `app.js`، `manifest.json`، `sw.js`، `icon-192.png`، `icon-512.png`
3. **Settings → Pages** → Source: **Deploy from a branch** → Branch **main** و پوشه‌ی **/ (root)** → **Save**
4. بعد از یکی دو دقیقه آدرس `https://یوزرنیم.github.io/اسم-مخزن/` ساخته می‌شود.
5. در Chrome گوشی باز کنید → منوی ⋮ → **Install app**.
6. دکمه‌ی ⚙ → کلید API را بزنید → Provider و Model را انتخاب کنید → ذخیره.

## نکات مهم
- کلید API فقط روی خود گوشی (localStorage) ذخیره می‌شود، نه در فایل‌ها.
- جستجوی وب (SEARCH) فقط با Gemini کار می‌کند، چون ابزار Google Search فقط در API گوگل هست. وقتی روشن است، فراخوانی ابزارهای بالا موقتاً غیرفعال می‌شود (محدودیت خود Gemini: هم‌زمان Search و Function Calling ممکن نیست).
- باز کردن اپ فقط برای برنامه‌هایی با لینک مستقیم کار می‌کند (تلگرام، واتساپ، اینستاگرام، یوتیوب، اسپاتیفای، ایمیل، دیسکورد، توییتر، نتفلیکس، نقشه، تماس، پیامک، Play Store). دکمه‌ی «↗ باز کن» زیر پاسخ را باید بزنید.
- دسترسی به GPS و باتری فقط با اجازه‌ی مرورگر و روی https کار می‌کند؛ GitHub Pages خودش https است.
- این نسخه را با یک API جعلی در مرورگر کامل تست کردم (رندر، ابزارها، خطاها)، ولی با کلید واقعی Gemini/Anthropic تست نشده؛ اگر رفتار غیرمنتظره دیدید بگویید.

## عیب‌یابی سریع
- **پیام «کلید API نامعتبر است»**: در ⚙ کلید و Provider را چک کنید.
- **«نام مدل پیدا نشد»**: نام مدل را در ⚙ تصحیح کنید (مثلاً `gemini-2.5-flash`).
- **میکروفون کار نمی‌کند**: باید از Chrome و روی https (نه file باز شده مستقیم) استفاده کنید و اجازه‌ی میکروفون بدهید.
- **صدای فارسی نمی‌آید**: موتور Text-to-speech فارسی در تنظیمات گوشی نصب کنید.
